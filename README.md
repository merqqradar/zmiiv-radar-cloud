# Радар Зміїв — хмарна версія

Код для розгортання на Railway. Читає публічні сторінки Telegram-каналів
(https://t.me/s/<канал>) — файл сесії Telethon не потрібен і сюди
не завантажується (він дає повний доступ до акаунту Telegram).

Потрібні змінні середовища: BOT_TOKEN, TARGET_CHAT_ID.
Запуск: python cloud_main.py (див. Procfile).
